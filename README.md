# xvcf.dev-v5

Heya, welcome to yet another version of my website!

My website only really shows my projects and the music I make. It also includes a footer with some contact information.

## Tech Used

This site was made in Next.js. For the CSS, I used TailwindCSS. Scripts were written in TypeScript, since I prefer it over JavaScript. The site is hosted on Vercel.

## Demo

You can check out the live demo of the website [here](https://xvcf.dev/).

## Development

If you (for some reason) want to run this site locally, simply clone the repo, install the dependencies using `bun` and run it!

```bash
git clone https://github.com/RafaeloxMC/xvcf.dev-v5.git
cd xvcf.dev-v5
bun install
bun run dev
```
